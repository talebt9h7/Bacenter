# Bellroy Admin v37 — Bilingual Sidebar

This version builds on v36 and translates the admin sidebar using the central bilingual i18n dictionary.

- English / Arabic labels for all sidebar groups and links.
- Arabic uses the existing RTL foundation from v36.
- English keeps LTR.
- No database schema or API changes.
- No route/path changes; internal route keys remain English.
- Sidebar actions View storefront and Sign out are bilingual too.
