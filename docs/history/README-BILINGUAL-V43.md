# Bellroy v43 — Orders bilingual

This version continues the bilingual admin rollout on top of v42.

## Orders
- Orders list, filters, tabs, table headers, actions and empty states use the central bilingual translation layer.
- Manual order modal is bilingual.
- Edit order modal is bilingual.
- Order detail labels and status labels use Arabic/English based on the selected admin language.
- Iraq governorate values remain data-driven and are not changed.
- No database schema changes are included in v43.

## Validation
ZIP integrity should be checked before delivery. Full Next.js typecheck requires the project's node_modules/environment and is not claimed here.
