# V93 — Profit Cost & Arabic Fixes

## إصلاح تكلفة المنتج
- تكلفة الشراء المخزنة في كل عنصر طلب أصبحت **تكلفة الوحدة** وليست إجمالي تكلفة الكمية.
- استهلاك FIFO يعيد متوسط تكلفة الوحدة عند استخدام أكثر من دفعة.
- مثال: 50 قطعة × 15,500 د.ع = 775,000 د.ع إجمالي تكلفة.

## إصلاح الربح
- ربح الوحدة = سعر البيع للوحدة − تكلفة الوحدة.
- ربح المنتج = ربح الوحدة × الكمية.
- الطلب الحالي UR-M-9EA688 تم تصحيح لقطة تكلفته إلى 15,500 د.ع للوحدة وربحه المسجل إلى 1,175,000 د.ع بناءً على تكلفة 10$ وسعر صرف 1,550 وسعر بيع 39,000 د.ع.
